Here are some frequently used **SQL `ALTER` commands** for modifying database tables:

### **1. Add a Column**
```sql
ALTER TABLE customers ADD COLUMN age INT;
```

### **2. Add Multiple Columns**
```sql
ALTER TABLE customers ADD COLUMN gender VARCHAR(10), ADD COLUMN dob DATE;
```

### **3. Modify a Column (Change Data Type)**
```sql
ALTER TABLE customers MODIFY COLUMN phone VARCHAR(20);
```

### **4. Rename a Column**
```sql
ALTER TABLE customers CHANGE COLUMN phone contact_number VARCHAR(20);
```

### **5. Drop a Column**
```sql
ALTER TABLE customers DROP COLUMN age;
```

### **6. Rename a Table**
```sql
ALTER TABLE customers RENAME TO client_data;
```

### **7. Add a Constraint (e.g., UNIQUE, NOT NULL)**
```sql
ALTER TABLE customers MODIFY COLUMN email VARCHAR(50) UNIQUE NOT NULL;
```

### **8. Drop a Constraint**
```sql
ALTER TABLE customers DROP INDEX email;  -- For UNIQUE constraint
```

### **9. Add a Foreign Key**
```sql
ALTER TABLE orders ADD CONSTRAINT fk_customer FOREIGN KEY (customer_id) REFERENCES customers(customer_id);
```

### **10. Remove a Foreign Key**
```sql
ALTER TABLE orders DROP FOREIGN KEY fk_customer;
```

These `ALTER` commands help modify table structures dynamically. 🚀

### **SQL Queries for `ROLLBACK` and `SAVEPOINT`**  
Used in **transaction management** to control commits and rollbacks.  

---

### **1. Using `ROLLBACK` to Undo Changes**
```sql
START TRANSACTION;

UPDATE customers SET city = 'Delhi' WHERE customer_id = 1;

ROLLBACK;  -- Undo the update
```
✅ **Effect:** The `city` value remains unchanged.

---

### **2. Using `SAVEPOINT` to Partially Rollback**
```sql
START TRANSACTION;

UPDATE customers SET city = 'Delhi' WHERE customer_id = 1;
SAVEPOINT sp1;  -- Savepoint created

UPDATE customers SET country = 'India' WHERE customer_id = 1;
SAVEPOINT sp2;  -- Another savepoint

ROLLBACK TO sp1;  -- Undo only the second update
```
✅ **Effect:**  
- The `city` update remains.  
- The `country` update is undone.

---

### **3. Releasing a Savepoint**
```sql
RELEASE SAVEPOINT sp1;
```
✅ **Effect:** `sp1` is removed, so it can't be rolled back.

---

### **4. Committing a Transaction**
```sql
COMMIT;
```
✅ **Effect:** Saves all changes permanently.

These commands ensure safe database updates. 🚀

### **`GRANT` and `REVOKE` Queries in SQL**  

In SQL, **`GRANT`** is used to give privileges to users, and **`REVOKE`** is used to take them away. These are widely used in **database security management**.  

---

## **🔹 `GRANT` Query (Giving Privileges)**
### **1️⃣ Grant SELECT on a table**
```sql
GRANT SELECT ON customers TO 'user1'@'localhost';
```
✅ Allows `user1` to read data from the `customers` table.

### **2️⃣ Grant Multiple Privileges**
```sql
GRANT SELECT, INSERT, UPDATE ON orders TO 'user2'@'localhost';
```
✅ Allows `user2` to **read, insert, and update** records in the `orders` table.

### **3️⃣ Grant ALL Privileges on a database**
```sql
GRANT ALL PRIVILEGES ON sales_db.* TO 'admin_user'@'%';
```
✅ Gives **full control** of `sales_db` to `admin_user` from **any host** (`%` means any IP).

### **4️⃣ Grant Privileges with GRANT OPTION**
```sql
GRANT ALL PRIVILEGES ON customers TO 'manager'@'localhost' WITH GRANT OPTION;
```
✅ Allows `manager` to **give** these privileges to other users.

---

## **🔹 `REVOKE` Query (Removing Privileges)**
### **1️⃣ Revoke SELECT from a user**
```sql
REVOKE SELECT ON customers FROM 'user1'@'localhost';
```
❌ Removes `SELECT` permission from `user1`.

### **2️⃣ Revoke Multiple Privileges**
```sql
REVOKE SELECT, INSERT ON orders FROM 'user2'@'localhost';
```
❌ `user2` can no longer **read or insert** into the `orders` table.

### **3️⃣ Revoke ALL Privileges**
```sql
REVOKE ALL PRIVILEGES ON sales_db.* FROM 'admin_user'@'%';
```
❌ Removes all permissions from `admin_user`.

---

## **🔹 Check User Privileges**
```sql
SHOW GRANTS FOR 'user1'@'localhost';
```
✅ Displays the permissions assigned to `user1`.

---

## **Key Points**
🔹 **`GRANT`** → Gives privileges.  
🔹 **`REVOKE`** → Removes privileges.  
🔹 **`WITH GRANT OPTION`** → Allows users to grant permissions to others.  
🔹 **Use `SHOW GRANTS`** to check assigned privileges.
