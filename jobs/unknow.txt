6. Arguments in Python Functions
-> 1. Positional Arguments:
These are the most common type of arguments and are passed in the order they are defined.
python
-> 2. Keyword Arguments:
These allow you to pass arguments using the parameter names, regardless of their order.
-> 3. Default Arguments:
These are used to define default values for parameters. If an argument is not provided, the default value is used.
-> 4. Variable-Length Arguments:
- *args: Allows you to pass a variable number of positional arguments.
- **kwargs: Allows you to pass a variable number of keyword arguments.
-> 5. Positional-Only and Keyword-Only Arguments:
- Positional-Only (/): Forces some arguments to be passed positionally.
- Keyword-Only (*): Forces some arguments to be passed by keyword.

9. In Python, **SOLID** refers to a set of **five object-oriented design principles** that help make software more understandable, flexible, and maintainable. SOLID is an acronym for:

---

### **S – Single Responsibility Principle (SRP)**
> A class should have only one reason to change.
🔹 **Meaning:** Each class should do only one thing. If it has more than one responsibility, it should be split.

### **O – Open/Closed Principle (OCP)**
> Software entities should be open for extension but closed for modification.
🔹 **Meaning:** You should be able to add new features without changing existing code.

### **L – Liskov Substitution Principle (LSP)**
> Subclasses should be substitutable for their base classes.
🔹 **Meaning:** Objects of a subclass should behave correctly when used in place of the superclass.

### **I – Interface Segregation Principle (ISP)**
> Clients should not be forced to depend on methods they do not use.
🔹 **Meaning:** Avoid creating large, bloated interfaces. Split them into smaller ones.

### **D – Dependency Inversion Principle (DIP)**
> High-level modules should not depend on low-level modules. Both should depend on abstractions.
🔹 **Meaning:** Code should rely on what something does, not on how it’s implemented — so you can swap implementations without breaking anything.
