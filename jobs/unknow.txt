6. Arguments in Python Functions
-> 1. Positional Arguments:
These are the most common type of arguments and are passed in the order they are defined.
python
-> 2. Keyword Arguments:
These allow you to pass arguments using the parameter names, regardless of their order.
-> 3. Default Arguments:
These are used to define default values for parameters. If an argument is not provided, the default value is used.
-> 4. Variable-Length Arguments:
- *args: Allows you to pass a variable number of positional arguments.
- **kwargs: Allows you to pass a variable number of keyword arguments.
-> 5. Positional-Only and Keyword-Only Arguments:
- Positional-Only (/): Forces some arguments to be passed positionally.
- Keyword-Only (*): Forces some arguments to be passed by keyword.

8. RESTful APIs
“Yes, I have worked with RESTful APIs. I used HTTP methods like GET for retrieving data and POST for creating data. I also understand RESTful principles, like working with resources, statelessness, and using appropriate status codes.”

Status Code	 Meaning	    When to Use
200	OK	                    Request was successful and the server returns the requested data.
201	Created	                Resource has been successfully created.
204	No Content	            Request is successful but there is no content to return.
400	Bad Request	            The request was malformed or invalid.
401	Unauthorized	        Authentication is required or has failed.
403	Forbidden	            The server understood the request but refuses to authorize it.
404	Not Found	            The requested resource was not found.
500	Internal Server Error	The server encountered an unexpected condition.
502	Bad Gateway	            Invalid response received from an upstream server.
503	Service Unavailable	    The server is temporarily unable to handle the request.
