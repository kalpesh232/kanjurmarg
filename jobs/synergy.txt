########## key differences between Django and Flask frameworks

Flask :
Description: Flask is a lightweight, micro web framework ideal for creating web servers. It provides flexibility, allowing developers to choose and integrate only the components needed for a specific project.
Example: If you want to build a small to medium-sized application and have control over the components you use, Flask is a great choice.

##########  handle database operations in Django and Flask

Django:

Database Handling :
1. Django has a built-in database file called SQLite, making it easy for developers to start without additional configurations.
2. Models in Django classes automatically translate into database tables, simplifying CRUD operations.
3. To use MySQL instead of SQLite, we have to install mysqlclient and  modifications in the settings file are needed, providing database credentials.

Flask:

Database Handling:
1. Flask doesn't have built-in database operations, giving developers the flexibility to choose databases.
2. Developers can also use SQLAlchemy, or Database operations can be performed using traditional methods, like manually writing SQL queries.

### Corrected Explanation:

- **Merge**: Combines DataFrames based on common columns or indices. By default, it returns only matching rows (inner join).  
- **Join**: Combines DataFrames based on index. Can specify left, right, or inner join.  
- **Concatenate**: Stacks DataFrames vertically or horizontally. Fills missing values with NaN.
