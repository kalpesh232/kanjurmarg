11.Explain how request is processed in django? (U V M H T F)
- Django URLs are responsible for mapping user requests to specific functions (views) in the application. They    define the routing mechanism within a Django project.
- Matching view function is called, which processes the request and generates a response. This may involve querying the database, processing forms, etc.
- Middleware allows you to process requests and responses globally. It can modify requests before they reach the view and responses before they are sent back to the client. Middleware can handle tasks like authentication.
- The view function returns an HTTP response object. This can be a rendered HTML page, JSON data.
- If the view function returns a template response, Django renders the template with context data and sends the resulting HTML back as part of the HTTP response.
- The final response is sent back to the client.

12.Django ORM 
-> Django ORM (Object-Relational Mapping) allows developers to interact with the database using Python code instead of raw SQL queries, reducing the chances of mistakes. It maps database tables to Python classes and provides built-in methods like get, filter, create, save, and delete to handle database operations automatically. This makes database management easier and more efficient.

15.get and filter in django
-get() Method
Retrieves a single object that matches the given query parameters.
Returns a single instance of the model.
Raises DoesNotExist if no objects match the query.
Raises MultipleObjectsReturned if more than one object matches the query.
-filter() Method
Retrieves a queryset of objects that match the given query parameters.
Returns a queryset containing all matching objects.
If no objects match, it returns an empty queryset.
