-> Encapsulation (BankAccount)
1. Encapsulation in Python is like putting data and the actions that work on that data into a box called a 
class. 
2. This helps to organize and protect the data, keeping some parts private ( using double underscores) 
and others protected (using a single underscore). 
3. The double underscore makes it harder to access and modify, acting as a stronger form of protection. It stops accidental messing up of data, making our code safer and more organized.
4. You can't directly access private variables from outside the class, but it's not impossible. You can still
 access them indirectly by Creating an instance of class. 
A. Public Variable: Accessible anywhere. Example: obj.var
B. Protected Variable: Meant for class and subclasses. Prefix with _. Example: obj._var
C. Private Variable:  Accessible only inside the class. Prefix with __. Example: obj.__var

->  session.commit() and session.flush() 

-: session.commit():
The commit() method is used to save any changes made during the current session to the database.
When you add, update, or delete objects within a session, those changes are not immediately reflected in the database. Committing the session makes those changes permanent.
It is typically used at the end of a logical unit .

-: session.flush():
The flush() method is used to update the session's state with the database, but it doesn't commit the transaction.
Unlike commit(), flush() doesn't end the transaction, so you can continue making changes before eventually committing.

->  Global Interpreter Lock (GIL)
The Global Interpreter Lock (GIL) in Python is like a traffic cop for threads. It makes sure only one thread can execute Python code at a time, preventing conflicts and simplifying the management.

->  Django, signals
In Django, signals are a way for different parts of your app to talk to each other. They allow one part to send a message when something happens, and other parts can listen for that message and react to it. It helps keep different parts of your app loosely connected, making it easier to change and maintain. For example, when you save something in the database, a signal can be sent, and other parts can respond to it, like sending a notification.

-> Generators over  for loop 
Generators in Python are memory-efficient because they produce values on-the-fly, one at a time, as you iterate over them. They don't store the entire sequence of values in memory all at once, unlike a regular for loop. This is especially helpful when working with large datasets, as it avoids using excessive memory since values are generated only when needed during iteration.

-> What is MQTT?
-
MQTT, which stands for Message Queuing Telemetry Transport.
MQTT is a messaging protocol used for communication between devices with limited bandwidth. In MQTT, the "broker" is like a hub that manages messages. Devices subscribe to "topics" they are interested in, and the broker ensures messages reach the right devices. "Publish" is sending a message, and "subscribe" is receiving messages on a specific topic. It's a simple and efficient way for devices to communicate in scenarios like IoT

-> What is the difference between a class method and an instance method and static method in Python?
->(O M D C A)

Instance Method:
Operates on an instance of the class.
Can access and modify the instance's attributes.
Defined using the def keyword inside the class, with self as the first parameter.
Called on an instance of the class: instance.method().
Instance attributes are accessed using self inside the class.

Class Method:
Operates on the class itself, rather than an instance.
Cannot access or modify instance-specific attributes.
Defined using the @classmethod decorator, with cls as the first parameter.
Called on the class: Class.method().
Class attributes are accessed directly using the class name .

Static Method: Independent of instance and class.
Cannot access instance or class attributes.
Defined using @staticmethod.
Used for utility/helper functions.
Called using Class.method() or instance.method().- (F U M D U)
