1. How can you secure you app in django
- I secure my Django app by using CSRF protection, XSS protection, Django ORM to prevent SQL injection, storing SECRET_KEY in .env, enabling HTTPS, setting ALLOWED_HOSTS, and keeping DEBUG=False in production. I also use strong authentication and validate all user inputs. 

2. Have you deploy any app or project ?
- Yes, I have deployed applications, mainly within our internal team network. I set up the app on a local server that was accessible to 4–5 colleagues on the same Wi-Fi/LAN. For deployment, I followed the standard process: created a virtual environment, installed dependencies, configured Gunicorn as the application server, and set up Nginx as a reverse proxy. I also created a systemd service to keep the app running and monitored logs for troubleshooting.

```nginx

    server_name 192.168.1.5;

    location / {
        proxy_pass http://unix:/run/stokapp.sock;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_redirect off;
    }
}
